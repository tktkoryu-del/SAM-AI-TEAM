# SAM AI TEAM

نظام تشغيل وإدارة مشاريع SAM من التخطيط إلى التسليم والتحقق.

> **نطاق هذا المستودع:** قوالب تشغيل، حوكمة، معايير هندسية، جودة، إنتاج محتوى، وتسويق. لا يحتوي على أسرار أو بيانات شخصية أو مفاتيح وصول.

## ابدأ من هنا
1. اقرأ [ميثاق الفريق](docs/governance/CHARTER.md).
2. راجع [الأدوار والمسؤوليات](docs/governance/ROLES.md).
3. استخدم [دورة التنفيذ](docs/operations/DELIVERY_LIFECYCLE.md) لكل مشروع.
4. طبّق [معيار التنفيذ المستقل](docs/operations/AUTONOMOUS_EXECUTION_STANDARD.md).
5. ابدأ بالبحث الحديث عبر [بروتوكول الترند والتقنيات](docs/operations/TREND_AND_TECH_RESEARCH_PLAYBOOK.md).
6. وجّه العمل عبر [كتالوج أدوات الذكاء الاصطناعي](docs/engineering/AI_TOOL_ROUTING_CATALOG.md).
7. لا تسلّم قبل اجتياز [بوابات الجودة](docs/quality/QUALITY_AND_RELEASE_GATES.md).
8. انسخ القوالب من `templates/`.

## التخصصات
CEO، COO، البحث والاستخبارات، الاستراتيجية والنمو، CTO، التصميم، إنتاج الفيديو، صناعة المحتوى، التسويق، إدارة المنصات، المالية، الجودة والأمان.

## قواعد حاسمة
- لا نشر أو دفع أو شراء أو التزام خارجي دون موافقة صريحة.
- لا كلمات مرور أو رموز تحقق أو مفاتيح API داخل Git.
- لا إعلان عن اكتمال دون دليل قابل للفحص.
- افصل الحقائق المؤكدة عن الافتراضات.
- كل تغيير تقني يمر بمراجعة واختبار وتوثيق.
- لا تُعتبر القوالب أو الخطط بديلاً عن تنفيذ المنتج واختباره.
