# إجراء إنتاج الفيديو القصير

## المدخلات
- المنصة والمدة ونسبة الأبعاد.
- الجمهور والهدف ورسالة الفيديو.
- اللهجة المطلوبة ومصدر النص.
- وصف الشخصية/الشخصيات ومراجع الصوت إن وجدت.
- حقوق الصور والموسيقى والأصول.

## سير الإنتاج
1. فكرة واحدة وخطاف قوي في أول 1–2 ثانية.
2. كتابة نص منطوق باللهجة المطلوبة، ثم تدقيقه بواسطة متحدث متمكن.
3. تقسيم المشاهد وتحديد المتحدث في كل لقطة.
4. توليد/تسجيل الصوت ومراجعته قبل التحريك.
5. تحريك الشفاه للشخصية المتحدثة فقط؛ تثبيت أفواه بقية الشخصيات.
6. مزامنة الشفاه مع الصوت، لا مع النص المكتوب وحده.
7. مونتاج وإضافة ترجمة واضحة ومتزامنة.
8. فحص النطق، اللهجة، التوقيت، الصوت، الصورة، والحقوق.
9. تصدير نسخة رئيسية ونسخ مناسبة للمنصات.
10. الحصول على موافقة المستخدم قبل النشر.

## فحص اللهجة والصوت
- لا تعتمد على الترجمة الآلية وحدها للهجة العراقية.
- استمع للنص كاملاً دون صورة قبل التحريك.
- افحص أسماء الشخصيات والكلمات المحلية والأرقام.
- إذا كان النطق غير طبيعي، أعد تسجيل الصوت قبل تحريك الشفاه.
- افحص تزامن الفم إطارياً في اللقطات القريبة.

## قائمة فحص قبل التسليم
- [ ] النص مطابق للهجة المطلوبة.
- [ ] لا توجد كلمات مبتورة أو نطق خاطئ.
- [ ] المتحدث الصحيح وحده يحرك شفتيه.
- [ ] تزامن الشفاه مقبول في كل لقطة.
- [ ] لا توجد قفزات أو تشوهات بصرية.
- [ ] الموسيقى والمؤثرات مرخصة أو أصلية.
- [ ] الترجمة صحيحة ومتزامنة.
- [ ] التصدير بالمقاس والترميز المطلوبين.
- [ ] تمت مشاهدة الملف النهائي كاملاً.
- [ ] النشر لم يتم دون موافقة صريحة.

## بيانات التسليم
اسم الملف، المدة، الدقة، نسبة الأبعاد، المنصة، نسخة النص، أداة الإنتاج، نتيجة الفحص، القيود المعروفة.
