# كتالوج توجيه أدوات الذكاء الاصطناعي — SAM AI TEAM

هذا الكتالوج يحدد متى نستخدم الاتصالات والأدوات المتاحة فعلياً في بيئة ChatGPT. وجود موصل لا يعني أن كل ميزة أو حساب خارجي مفعل؛ يجب فحص الإجراء المتاح والاتصال والصلاحيات قبل التنفيذ. لا تُخترع مفاتيح API ولا تُشارك الأسرار.

| المجال | الأداة/الاتصال المتاح | الاستخدام المناسب | التحقق المطلوب |
|---|---|---|---|
| البحث العميق | Exa، البحث عبر الويب | اكتشاف مصادر حديثة، منافسين، تقنيات، أبحاث واتجاهات | حداثة المصدر، الاستشهاد، التحقق المتقاطع |
| التصفح والتنفيذ على المواقع | TinyFish Browser | قراءة صفحات وتنفيذ خطوات متصفح مفوضة | معاينة الحالة، عدم إرسال/شراء/نشر دون موافقة |
| متابعة الويب | TinyFish Monitors | مراقبة شرط أو صفحة وفق جدول عند طلب المستخدم | تحديد النطاق والجدول والغرض؛ لا تفعيل مراقبة مدفوعة دون وضوح |
| الصور والفيديو | Higgsfield، fal | توليد وتحرير أصول بصرية وفيديو بحسب الإجراءات المتاحة | مراجعة الصوت/النص/الحقوق/المقاس والمخرجات |
| الفيديو والأفاتار | HeyGen | فيديوهات متحدث وأفاتار ودبلجة/ترجمة بحسب الميزات المتاحة | اختبار نطق العربية واللهجة ومزامنة الشفاه |
| التصميم | Canva، Figma | تصاميم، أصول، عروض، واجهات ونماذج | فحص قابلية التحرير والهوية والقياسات |
| تطوير البرمجيات | GitHub | ملفات المصدر، الفروع، PR، CI، مراجعة التغييرات | build، tests، security، artifacts |
| توثيق وإدارة المعرفة | Notion | حفظ القرارات والخطط وسجلات المشاريع | الروابط الصحيحة وعدم تخزين أسرار |
| بيانات التسويق | Supermetrics / Metricool عند الاتصال | تحليل الأداء والقنوات والجدولة | صلاحية الحساب، حداثة البيانات، موافقة النشر |

## قاعدة التوجيه
- البحث قبل الإنشاء عندما تتغير المعايير أو الاتجاهات.
- اختر أقل مجموعة أدوات تحقق نتيجة احترافية؛ لا تستخدم كل الأدوات لمجرد توفرها.
- لا تنقل ملفات خاصة إلى خدمة خارجية إلا إذا كان ذلك ضرورياً ومصرحاً به.
- افحص سياسة الاحتفاظ والخصوصية عند التعامل مع صور شخصية أو بيانات حساسة.
- إذا كانت الأداة غير متصلة أو الإجراء غير متاح، اذكر ذلك بدقة واستخدم بديلاً متاحاً.
- لا تُعلن أن الأدوات "مربوطة" بحسابات المستخدم الخارجية إلا بعد التحقق من الاتصال والصلاحيات.

## حزم التنفيذ حسب نوع المهمة
- فيديو قصير: بحث اتجاه → فكرة وسيناريو → توليد/مونتاج → تدقيق نطق ولهجة → تدقيق صوت/شفاه/نص → تصدير.
- تطبيق: بحث سياسات وإصدارات → متطلبات → تصميم معماري → تنفيذ → اختبارات ثابتة ووحدات وبناء → مراجعة أمن وخصوصية → إصدار تجريبي.
- حملة تسويقية: بحث جمهور ومنافسين واتجاه → عرض ورسالة → مواد إبداعية → إعداد الحملة → تدقيق الميزانية والاستهداف → موافقة قبل الإطلاق.
- تصميم واجهة: بحث نمط وتجارب → brief → تدفقات → تصميم Figma/Canva → مراجعة استخدام وإتاحة → تسليم.
- محتوى قناة: تحليل بيانات القناة المتاحة → بحث الاتجاهات → زاوية أصلية → إنتاج → عناوين/وصف/وسوم → مراجعة سياسة المنصة → موافقة قبل النشر.
