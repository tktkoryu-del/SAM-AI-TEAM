# تشغيل القنوات وقياس الأداء

## قواعد التشغيل
- تقويم محتوى موحد لكل منصة.
- تكييف العنوان والوصف والوسوم لكل منصة بدلاً من النسخ الآلي.
- لا شراء مشاهدات أو متابعين أو تفاعل وهمي.
- لا نشر أو جدولة دون موافقة صريحة.
- لا تستنتج النجاح من المشاهدات وحدها.

## مؤشرات القياس
### YouTube
المشاهدات، وقت المشاهدة، متوسط مدة المشاهدة، نسبة الاحتفاظ، مرات الظهور، CTR، المشتركين المكتسبين، مصادر الزيارات.

### TikTok / Reels
المشاهدات، متوسط وقت المشاهدة، إكمال الفيديو، إعادة المشاهدة، المشاركات، الحفظ، التعليقات، زيارات الملف والمتابعون المكتسبون.

### مؤشرات الجودة
- أداء أول ثانيتين.
- نسبة إكمال الفيديو.
- تفاعل ذو معنى لكل ألف مشاهدة.
- تحويل المشاهد إلى متابع.
- انتظام الإنتاج دون هبوط الجودة.

## تقرير أسبوعي
- الفترة والمنصات.
- البيانات الخام ومصدرها.
- أفضل 3 محتويات ولماذا.
- أضعف 3 محتويات والفرضية التفسيرية.
- تغييرات مقترحة قابلة للاختبار.
- الميزانية والنتائج إن وجدت.
- لا تخلط بين الأرقام اليومية والتراكمية.
- اذكر البيانات الناقصة ولا تخترع قيماً.
