# بوابات الجودة والتسليم

## بوابة البحث
- مصادر حديثة وموثوقة للمعلومات المتغيرة.
- توثيق تاريخ البحث ومصدر كل ادعاء مهم.
- تمييز الحقائق عن التوقعات.

## بوابة المحتوى والفيديو
- صحة النص والإملاء والترجمة.
- نطق عربي/لهجة صحيحة وفق الطلب.
- مزامنة شفاه عند وجود شخصية ناطقة.
- لا حركة فم لشخصية صامتة.
- وضوح الصوت وخلوه من التشويش والتقطيع.
- اتساق المشاهد والألوان والشخصيات.
- الأبعاد والدقة ومعدل الإطارات والصيغة المطلوبة.
- مراجعة حقوق الأصول والموسيقى وعدم تقليد شخص حقيقي بطريقة مضللة.

## بوابة البرمجيات
- build نظيف قابل للتكرار.
- اختبارات وحدات/تكامل مناسبة.
- فحص الاعتماديات والثغرات والأذونات.
- اختبار RTL وإمكانية الوصول عند دعم العربية.
- معالجة حالات الرفض والأذونات المحدودة وانقطاع الشبكة.
- لا تسريب أسرار أو بيانات شخصية في المستودع والسجلات.
- artifact منشأ فعلياً ويمكن تنزيله، مع checksum عند الإمكان.
- لا يُسمى Debug build إصدار متجر.

## بوابة التسليم
- المخرج موجود ويمكن فتحه.
- تمت مراجعة المخرج نفسه لا الاكتفاء بنجاح أداة التوليد.
- أُعيد الاختبار بعد الإصلاح.
- تذكر القيود غير المحسومة.
- موافقة المستخدم مطلوبة لأي نشر أو إرسال أو دفع أو شراء أو التزام خارجي.

## سجل العيوب
لكل عيب: الوصف، الشدة، خطوات إعادة الإنتاج، السبب الجذري، الإصلاح، نتيجة إعادة الاختبار. لا تخفِ العيوب ولا تضع "نجاح" دون دليل.
