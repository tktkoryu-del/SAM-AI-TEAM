# الأمن والخصوصية

## الأسرار
- يمنع رفع كلمات المرور، مفاتيح API، رموز OAuth، مفاتيح التوقيع، ملفات keystore، أو رموز الاسترداد.
- استخدم مدير أسرار أو متغيرات بيئة خارج Git.
- إذا ظهر سر في commit، أوقف استخدامه ودوّره/ألغِه فوراً، ثم نظّف التاريخ عند الحاجة. حذف الملف وحده لا يبطل السر.

## الحسابات والصلاحيات
- أقل صلاحية لازمة.
- MFA للحسابات الداعمة.
- لا تشارك رموز التحقق مع أي شخص أو مساعد.
- راجع التطبيقات المتصلة والصلاحيات دورياً.
- لا تتجاوز الحماية أو ضوابط المنصات.

## البيانات الشخصية
- اجمع أقل قدر ممكن.
- حدد الغرض وفترة الاحتفاظ.
- لا تضع بيانات مستخدمين حقيقية في أمثلة الاختبار.
- استخدم بيانات اصطناعية أو منزوعة الهوية.
- لا تسجل رموز الجلسات أو محتوى حساساً في السجلات.

## التعامل مع الحوادث
1. أوقف النشاط المتأثر.
2. احمِ الأدلة وسجّل الوقت والنطاق.
3. ألغِ أو دوّر بيانات الاعتماد المتأثرة.
4. قيّم الأثر والبيانات المتضررة.
5. أصلح السبب واختبر.
6. وثّق الحادث والإجراءات الوقائية.

## حالة المستودع
هذا المستودع عام. لا تضف شيفرة مملوكة أو معلومات سرية أو بيانات شخصية قبل تحويله إلى خاص ومراجعة محتواه.
