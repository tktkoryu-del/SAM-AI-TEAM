# SAM Recovery — المخاطر وبوابات الإصدار

## سجل المخاطر
| الخطر | الأثر | المعالجة |
|---|---|---|
| توقع المستخدم استرجاع كل ملف محذوف نهائياً | تضليل وفقدان ثقة | تحذير واضح قبل الفحص، وتصنيف دقيق لكل نتيجة |
| اختلاف صلاحيات Android حسب إصدار النظام | نتائج غير متسقة | مصفوفة أجهزة/إصدارات واختبارات صلاحيات |
| عدم إمكانية الوصول إلى Recently Deleted على iOS من تطبيق خارجي | ادعاء استعادة غير صحيح | توجيه المستخدم إلى Photos وعدم تقديم زر استعادة وهمي |
| صلاحيات واسعة غير ضرورية | رفض متجر ومخاطر خصوصية | أقل صلاحية واستخدام SAF/Photo Picker |
| تسريب أسماء الملفات في السجلات | كشف بيانات شخصية | تنقيح السجلات ومنع تسجيل المسارات |
| وجود مستودع الفريق العام | كشف الشيفرة/بيانات مستقبلية | لا تضاف أسرار أو بيانات مستخدمين؛ نقل كود المنتج إلى مستودع خاص قبل إضافة مصدر حساس |

## بوابات الإصدار
### G0 — تعريف المنتج
- [x] حدود الاستعادة مكتوبة بوضوح.
- [x] نطاق MVP محدد.
- [x] الخصوصية المحلية هي الوضع الافتراضي.

### G1 — هيكل المصدر
- [ ] مستودع تطبيق مخصص (خاص قبل إدخال بيانات أو أسرار).
- [ ] ملفات Gradle وAndroid Manifest وموارد RTL.
- [ ] مشروع Xcode وملفات entitlements المناسبة.
- [ ] تثبيت إصدارات SDK والاعتماديات.

### G2 — الوظائف
- [ ] فحص الوسائط المسموح بها.
- [ ] تصنيف مصدر كل نتيجة.
- [ ] إلغاء الفحص والتصدير.
- [ ] حالات الخطأ والرفض والنتائج الفارغة.

### G3 — الجودة والأمان
- [ ] نجاح بناء Android وiOS على بيئات موثقة.
- [ ] اختبارات الأجهزة الفعلية.
- [ ] اختبار صلاحيات محدودة ومرفوضة.
- [ ] تحقق عدم وجود نقل شبكة للوسائط.
- [ ] تدقيق RTL وإمكانية الوصول.

### G4 — ما قبل المتجر
- [ ] سياسة خصوصية منشورة ومطابقة للسلوك الفعلي.
- [ ] صور وبيانات متجر لا تتضمن ادعاءات مضللة.
- [ ] مراجعة سياسات Google Play وApp Store الحالية.
- [ ] موافقة المستخدم الصريحة قبل أي نشر.

## حالة التنفيذ الآن
هذه الوثائق تحدد مواصفات وقرارات المنتج فقط. لم يتم بعد إنشاء تطبيق Android/iOS قابل للبناء، ولم يتم تشغيل اختبارات أو إصدار APK/IPA. لا يُعلن اكتمال التطبيق حتى اجتياز بوابات G1–G3.
